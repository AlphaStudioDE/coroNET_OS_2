# Standard coroNET Print Project

`coroNET.3mf` contains the standard enclosure parts and slicer settings for the physical coroNET hardware shared by OS 1 and OS 2.

File provenance:

- project owner: Damian Borkowski;
- inherited from the published coroNET OS 1 hardware package;
- OS 2 copy SHA-256: `8401D57EEB000F67472835271BCD914011E21432525D1C65161D691441DF44DA`;
- size: 3,709,563 bytes.

Inspect every plate and slicer profile before printing. Material behavior, printer calibration, inserts, magnets, cable clearances, and component tolerances may require adjustment.
